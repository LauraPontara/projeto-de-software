# Trabalhos — Disciplina Projeto de Software

Bem-vind@! Este repositório reúne os trabalhos da disciplina **Projeto de Software** (PUC Minas). O objetivo é centralizar a documentação, diagramas UML e arquivos auxiliares produzidos ao longo do curso.

## Conteúdo atual

- **sgo/** — SGO — Sistema de Gestão das Olimpíadas (trabalho em desenvolvimento)
	- `sgo/README.md` — descrição e detalhes do trabalho SGO
	- `sgo/codigos/` — arquivos PlantUML (`*.puml`) com os diagramas
	- `sgo/imagens/` — imagens geradas dos diagramas (`*.png`, `*.svg`)

## Estrutura (resumo)

```
README.md
sgo/
	README.md
	codigos/
		*.puml
	imagens/
```

## Observações

- O foco atual é modelagem UML e documentação; não há implementação de sistema neste repositório.
- Os diagramas-fonte em PlantUML estão em `sgo/codigos/` e as imagens exportadas em `sgo/imagens/`.
